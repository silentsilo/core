The minisign public key the SilentSilo updater checks a release against, and
the key the extraction tool is signed with. The tool is built from this
repository and published on silentsilo/desktop's release page.

Each file on the release page has a `.sig` beside it: the minisign
signature, base64 encoded once more, as the updater reads it. Decode it,
then verify with minisign:

    base64 -d silentsilo-extract-linux-x86_64.sig > silentsilo-extract-linux-x86_64.minisig
    minisign -Vm silentsilo-extract-linux-x86_64 -x silentsilo-extract-linux-x86_64.minisig -P <the key line below>

On Windows, in PowerShell:

    [IO.File]::WriteAllBytes("x.minisig", [Convert]::FromBase64String((Get-Content x.exe.sig -Raw)))
    minisign -Vm x.exe -x x.minisig -P <the key line below>
